## Overview

Xây dựng trang Landing Page sự kiện Khai trương 3M Pro Shop & 3M Training Center bằng Next.js. Giao diện tối sang trọng (Dark Theme) với màu đỏ chủ đạo của 3M, tích hợp form đăng ký nhận diện QR Code check-in.

## Tech Stack

- Frontend: Next.js App Router (TypeScript, React)
- Backend: Next.js API Routes
- Styling: Vanilla CSS (CSS Modules)
- Storage: Local JSON file (for guest registration list)
- Features: QR Code Generation (for check-in)
